# Fretstorm

A game for learning the note names on the guitar fretboard.

**Play it here:** https://hallma-dot.github.io/fretstorm/

It works on computers, tablets and phones (turn your phone sideways for the best view). Your progress is saved in your browser. To move it to another device, use the save code in Settings.

This folder holds the built game only. Don't edit `index.html` here by hand: it gets replaced each time the game is rebuilt.
